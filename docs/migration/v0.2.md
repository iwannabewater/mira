# Migrating to MIRA 0.2

MIRA 0.2 adds direct Qwen3-VL-Embedding inference and makes vector artifacts
portable and role-aware. Because MIRA is still before 1.0, this release removes
ambiguous Qwen3-VL names instead of preserving them as public aliases.

## Install and create a reference config

```bash
python -m pip install "mira-embed[inference-qwen3-vl-embedding]"
mira init-config \
  --preset qwen3-vl-embedding-2b-single-gpu-lora \
  --output mira.yaml
mira doctor --workflow inference --config mira.yaml
```

Repository config paths changed as follows:

| MIRA 0.1 | MIRA 0.2 |
| --- | --- |
| `configs/experiments/qwen3_vl_2b_single_gpu_lora.yaml` | `configs/experiments/qwen3_vl_embedding_2b_single_gpu_lora.yaml` |
| `configs/experiments/qwen3_vl_ecommerce.yaml` | `configs/experiments/qwen3_vl_embedding_ecommerce.yaml` |

## Update Python names

| MIRA 0.1 | MIRA 0.2 |
| --- | --- |
| `QwenEmbeddingSemantics` | `Qwen3VLEmbeddingSemantics` |
| `qwen_audit` | `qwen3_vl_embedding_audit` |

`Qwen3VLModel` remains in implementation notes only because it is the upstream
Transformers architecture class. Public MIRA capabilities always say
Qwen3-VL-Embedding.

## Migrate encoded vectors

`mira encode` now writes a `mira.encoded.v2` directory. A v2 manifest binds the
query or document role, normalization state, provenance, ordered shards, and
every file checksum. Mining and evaluation require those roles.

Re-encoding the original JSONL is preferred. If only a trusted v1 tensor bundle
remains, migrate it explicitly:

```bash
mira migrate-encoded \
  --input legacy-queries.pt \
  --output artifacts/queries \
  --role query \
  --normalization normalized \
  --shard-size 4096
```

Use `--normalization unnormalized` only when the legacy vectors were not
normalized. MIRA rejects that choice when legacy provenance already claims
L2-normalized inner-product semantics.

## Load existing exports

New export manifests use `pooling=last_token` and
`template=qwen3_vl_embedding`. The reader accepts the exact historical v0.1
pair `pooling=last_eos` and `template=qwen3_vl_emb` because that implementation
already pooled the terminal token. Mixed old and new labels are rejected.

Always provide the trusted export manifest checksum when loading a local
export. No compatibility rule bypasses file-set, checksum, model revision,
license, preprocessing, or representation checks.
